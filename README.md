נבנה מתוך ייצוא Markdown של מסמך Google Docs. כל 493 הסעיפים, 49 הכותרות
ו-14 התמונות מהמקור נמצאים בעמוד. ארבע תמונות שהכילו טבלאות ורשימות
(בדיקה חיצונית, טבלת חירום, גבהי טיסה, כללי VFR) תומללו גם לטקסט חי
כדי שיהיו קריאים בנייד וניתנים לחיפוש — התמונה המקורית מוצגת לצידן.
